# Skill: 讲座/分享类活动策划

## 触发条件
- 活动类型: "讲座" / "分享"
- 关键词匹配: `讲座 演讲 分享 学术 报告 seminar 交流会 研讨会 论坛 峰会 宣讲会 培训 公开课 大师课 经验分享 科普 座谈 茶话会`

## 标准流程 (SOP)

| 环节 | 时长 | 内容 | 互动方式 |
|------|:--:|------|------|
| 签到入场 | 20分钟 | 参与者签到，领取活动议程和反馈表，自由交流暖场 | 自由交流 |
| 开场致辞 | 10分钟 | 主持人介绍活动背景和流程，欢迎到场嘉宾 | 主持人引导 |
| 嘉宾分享 | 45分钟 | 邀请嘉宾围绕主题进行演讲，分享实践经验与行业洞察 | 问答互动 |
| 互动讨论 | 30分钟 | 参与者分组讨论，结合自身经历提出问题与见解，嘉宾巡回解答 | 小组讨论、嘉宾答疑 |
| 总结与自由交流 | 15分钟 | 主持人总结要点，颁发嘉宾纪念品，参与者自由交流与合影 | 合影留念 |

## 主持引导语

- 开场: `各位同学请到签到处登记，领取资料后可以先自由交流。`
- 欢迎: `欢迎大家来到今天的"[主题]"活动，让我们一起度过充实而有意义的时光！`
- 嘉宾介绍: `接下来有请今天的分享嘉宾，大家掌声欢迎！`
- 互动环节: `现在进入互动环节，请大家分成4-6人小组，围绕刚才的内容展开讨论。`
- 结束: `感谢嘉宾的精彩分享，也感谢大家的积极参与，让我们合影留念！`

## 所需物资

| 物资 | 规格 | 数量 |
|------|------|:--:|
| 签到表 | A4打印 | 5张 |
| 饮用水 | 瓶装550ml | 人数×1.2瓶 |
| 投影仪 | 高清，支持HDMI | 1台 |
| 音响设备 | 含无线话筒×2 | 1套 |
| 翻页笔 | 激光翻页 | 1支 |
| 白板/写字板 | 带白板笔 | 1块 |

## 约束

- 最少人数: 15人
- 建议教室容量: 参与人数 × 1.3
- 建议建筑: E教学楼
- 总时长: 约120分钟
