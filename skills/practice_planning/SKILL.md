# Skill: 实践活动类策划

## 触发条件
- 活动类型: "实践"
- 关键词匹配: `实践 动手 制作 DIY 手工 烘焙 实验 实训 操作 搭建 组装 花艺 编程 开发 hackathon 黑客松`

## 标准流程 (SOP)

| 环节 | 时长 | 内容 | 互动方式 |
|------|:--:|------|------|
| 签到与分组 | 15分钟 | 参与者签到，按报名的兴趣方向分组，发放工具包和操作指南 | 自由交流 |
| 指导讲解 | 20分钟 | 指导老师讲解操作要点、安全规范和预期成果 | 讲解互动 |
| 动手实践 | 60分钟 | 各组按照指导进行动手操作，指导老师巡回辅导 | 实践操作、小组协作 |
| 成果展示与互评 | 25分钟 | 各组展示实践成果，相互观摩评价，指导老师点评 | 展示交流、互评打分 |
| 总结与表彰 | 10分钟 | 颁发最佳实践奖和最佳创意奖，全体合影 | 合影留念 |

## 主持引导语

- 签到: `请签到后到指定区域领取工具包，找到自己小组的位置。`
- 指导: `在正式开始动手之前，我先给大家讲解"[主题]"的操作流程和注意事项。`
- 实践: `现在开始动手操作！有任何问题请举手，我们随时提供帮助。`
- 展示: `时间到！请各组派代表展示你们的成果，每组3分钟。`
- 结束: `大家的作品都非常出色，让我们为彼此的创意鼓掌！`

## 所需物资

| 物资 | 规格 | 数量 |
|------|------|:--:|
| 签到表 | A4打印 | 5张 |
| 饮用水 | 瓶装550ml | 人数×1.2瓶 |
| 工具包 | 含基础工具 | 人数÷4套 |
| 操作材料 | 根据主题准备 | 若干 |
| 安全手套 | 均码 | 人数双 |
| 投影仪 | 展示指导视频 | 1台 |
| 成果展示台 | 长桌 | 人数÷8张 |

## 约束

- 最少人数: 10人（分组活动）
- 建议教室容量: 参与人数 × 1.5（需要操作空间）
- 建议建筑: E教学楼
- 总时长: 约130分钟
