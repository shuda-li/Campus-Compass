# Skill: 运动/体育类活动策划

## 触发条件
- 活动类型: "运动" / "体育"
- 关键词匹配: `体育 运动 篮球 足球 跑步 健身 瑜伽 登山 骑行 游泳 武术 太极 羽毛球 乒乓球 排球 运动会`

## 标准流程 (SOP)

| 环节 | 时长 | 内容 | 互动方式 |
|------|:--:|------|------|
| 签到与热身 | 20分钟 | 参赛者签到，领取号码牌和活动T恤，在教练带领下进行热身 | 集体热身 |
| 开幕式与规则说明 | 10分钟 | 主持人介绍运动项目、比赛规则和安全注意事项 | 主持人引导 |
| 正式比赛/活动 | 60分钟 | 按照比赛规则进行正式比赛或体育活动 | 竞技比赛、团队协作 |
| 趣味挑战 | 20分钟 | 设置趣味关卡或挑战项目，增加活动趣味性和参与度 | 趣味互动 |
| 颁奖与合影 | 10分钟 | 公布成绩，为优胜者颁发奖牌和奖品，全体合影 | 合影留念 |

## 主持引导语

- 签到: `请大家签到后到热身区集合，我们进行赛前热身运动。`
- 开幕: `欢迎参加"[主题]"，请大家注意安全，友谊第一比赛第二！`
- 比赛: `比赛正式开始！大家加油！`
- 趣味: `正式比赛结束！接下来是趣味挑战环节，人人都能参与！`
- 结束: `恭喜各位优胜者！感谢所有人的热情参与！`

## 所需物资

| 物资 | 规格 | 数量 |
|------|------|:--:|
| 签到表 | A4打印 | 5张 |
| 运动器材 | 根据项目配置 | 若干 |
| 号码牌/背心 | 荧光色分队服 | 人数件 |
| 急救箱 | 含创可贴/云南白药/冰袋 | 2个 |
| 哨子/扩音器 | 裁判用 | 3个 |
| 饮用水 | 桶装水+纸杯 | 人数÷10桶 |

## 约束

- 最少人数: 20人
- 建议场地: 操场/体育馆（非教室）
- 总时长: 约120分钟
