# Skill: 演出类活动策划

## 触发条件
- 活动类型: "演出" / "晚会"
- 关键词匹配: `晚会 演出 文艺 才艺 迎新 毕业 联欢 庆典 party 嘉年华 音乐节 才艺展 年度盛典 文艺汇演 歌手大赛 音乐会 舞会 文化节 艺术节 合唱`

## 标准流程 (SOP)

| 环节 | 时长 | 内容 | 互动方式 |
|------|:--:|------|------|
| 观众入场 | 30分钟 | 观众凭票/邀请函入场，工作人员引导入座，发放节目单 | 有序入场 |
| 开场表演与致辞 | 15分钟 | 暖场表演拉开序幕，主持人介绍演出背景和节目安排 | 暖场表演 |
| 节目表演（上半场） | 45分钟 | 按照节目单依次进行主题表演，涵盖多种艺术形式 | 舞台表演 |
| 互动与中场休息 | 15分钟 | 观众投票/互动游戏环节，中场休息，工作人员准备下半场道具 | 观众投票、互动游戏 |
| 节目表演（下半场）与谢幕 | 45分钟 | 下半场节目继续，全体演职人员谢幕，颁发最佳节目奖 | 舞台表演、谢幕 |

## 主持引导语

- 入场: `各位观众请凭票入场，按指引入座，演出即将开始。`
- 开场: `欢迎来到"[主题]"的演出现场，今夜星光灿烂！`
- 上半场: `接下来请欣赏第一个节目……`
- 互动: `现在是互动环节，请大家拿起手机为最喜欢的节目投票！`
- 谢幕: `感谢所有演职人员的倾情奉献，感谢观众朋友们的热情支持！`

## 所需物资

| 物资 | 规格 | 数量 |
|------|------|:--:|
| 签到表 | A4打印 | 5张 |
| 饮用水 | 瓶装550ml | 人数×1.2瓶 |
| 舞台灯光 | 面光+追光+染色 | 1套 |
| 专业音响 | 含调音台+手持话筒×4 | 1套 |
| 投影/背景屏 | LED背景屏或投影幕 | 1块 |
| 节目单 | A4彩印 | 人数份 |
| 服装/道具 | 根据节目需求 | 若干 |

## 约束

- 最少人数: 50人
- 建议教室容量: 参与人数 × 1.3
- 建议建筑: E教学楼（报告厅）
- 总时长: 约150分钟
