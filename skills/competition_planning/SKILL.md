# Skill: 竞赛类活动策划

## 触发条件
- 活动类型: "竞赛"
- 关键词匹配: `竞赛 比赛 大赛 挑战赛 编程 辩论 答辩 contest 路演 创业赛 创新赛 演讲比赛 知识竞赛 黑客松 马拉松 hackathon 擂台赛 选拔赛 初赛 决赛`

## 标准流程 (SOP)

| 环节 | 时长 | 内容 | 互动方式 |
|------|:--:|------|------|
| 选手签到与抽签 | 30分钟 | 参赛选手签到确认身份，进行比赛顺序抽签，领取参赛证和规则说明 | 自主签到 |
| 开幕式 | 15分钟 | 主持人介绍比赛规则、评委阵容和评分标准，选手代表宣誓 | 主持人引导 |
| 正式比赛 | 90分钟 | 选手按抽签顺序进行主题竞赛，评委根据评分标准打分 | 现场竞技、评委打分 |
| 评委点评与颁奖 | 20分钟 | 评委代表对整体表现进行点评，公布名次并颁发奖项 | 点评互动、颁奖仪式 |
| 合影与闭幕 | 10分钟 | 全体参赛选手、评委和工作人员合影留念 | 合影留念 |

## 主持引导语

- 签到: `请各位选手到签到处确认信息并抽签，比赛将于15分钟后正式开始。`
- 开幕: `欢迎来到"[主题]"的现场！让我们共同见证精彩对决。`
- 比赛: `接下来有请第一位选手登场，让我们拭目以待！`
- 颁奖: `感谢所有选手的精彩表现，现在请评委代表进行点评……`
- 闭幕: `感谢大家的辛勤付出，让我们明年再见！`

## 所需物资

| 物资 | 规格 | 数量 |
|------|------|:--:|
| 签到表 | A4打印 | 5张 |
| 饮用水 | 瓶装550ml | 人数×1.2瓶 |
| 投影仪 | 高清，显示计时器 | 1台 |
| 计时器 | 大屏显示 | 1个 |
| 评分表 | A4打印，含评分标准 | 人数份 |
| 号码牌/参赛证 | 塑封卡片 | 人数×1.5个 |
| 证书/奖状 | A4，烫金字 | 10份 |

## 约束

- 最少人数: 20人
- 建议教室容量: 参与人数 × 1.5
- 建议建筑: E教学楼
- 总时长: 约165分钟
