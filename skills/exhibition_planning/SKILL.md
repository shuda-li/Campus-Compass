# Skill: 展览类活动策划

## 触发条件
- 活动类型: "展览"
- 关键词匹配: `展览 展销 展览会 展示 摄影展 画展 作品展 博览会 成果展 设计展`

## 标准流程 (SOP)

| 环节 | 时长 | 内容 | 互动方式 |
|------|:--:|------|------|
| 布展签到 | 30分钟 | 参展者签到并按编号布置展位，工作人员提供桌椅和展板 | 自主布展 |
| 开幕式 | 15分钟 | 主持人介绍展览主题和评选规则，宣布展览正式开始 | 主持人引导 |
| 自由观展 | 60分钟 | 观众自由参观各展位，与参展者交流讨论相关话题 | 自由参观、互动交流 |
| 观众投票与评选 | 20分钟 | 观众投票评选最佳作品，评委进行专业评审 | 投票互动 |
| 颁奖与闭幕 | 10分钟 | 公布评选结果，为获奖者颁发证书，全体合影 | 合影留念 |

## 主持引导语

- 布展: `请参展同学到指定编号的展位进行布置，有问题请联系工作人员。`
- 开幕: `欢迎来到"[主题]"展览现场，让我们一同感受创意的魅力！`
- 观展: `展览正式开始，请大家自由参观，可以随时与参展者交流。`
- 投票: `现在是投票环节，请为你最喜欢的作品投上一票！`
- 闭幕: `感谢所有参展者的精彩呈现，感谢观众的热情参与！`

## 所需物资

| 物资 | 规格 | 数量 |
|------|------|:--:|
| 签到表 | A4打印 | 5张 |
| 饮用水 | 瓶装550ml | 人数×1.2瓶 |
| 展板/展架 | 1.2m×0.9m，带挂钩 | 人数÷4块 |
| 长桌 | 1.8m | 人数÷4张 |
| 作品标签卡 | A5硬卡纸 | 人数张 |
| 投票箱 | 带锁 | 2个 |
| 选票 | A5纸，编号 | 人数张 |

## 约束

- 最少人数: 15人
- 建议教室容量: 参与人数 × 2.0（需要展位空间）
- 建议建筑: E教学楼（一楼大厅或大教室）
- 总时长: 约135分钟
