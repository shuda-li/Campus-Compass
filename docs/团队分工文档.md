## 🌍 全员 30 秒启动

```bash

cd Campus-Compass
```

### 成员 5：LLM 集成 + 全栈串联 + 文档 🔑 让 Agent 从模板变智能

**负责文件（6 个）**：`llm_client.py`、`config.py`、`main.py`、`.env.example`、`requirements.txt`、`.gitignore`

**核心洞察**：

> **整个系统目前走的是 Agent 自主推理（就是死的模板）。一旦你填上 API Key，LLM 接管创意生成，输出从"模板套话"变成"真正理解主题的个性化方案"。**
>
> 主题"MBTI"→ 规则引擎：笼统的"搭建知识交流平台"
> 主题"MBTI"→ LLM：知道 16 型人格、有测试问卷、按 E/I 分组的互动设计

| 任务         | 文件·行号                           | 具体操作                                      |
| ---------- | ------------------------------- | ----------------------------------------- |
| 创建 `.env`  | 复制 `.env.example` → `.env`      | 填入 `LLM_API_KEY=sk-xxx`                   |
| 配通 LLM     | `config.py` 第 6-8 行             | 如果用 DeepSeek：`LLM_API_URL` 改为 DeepSeek 地址 |
| 测试效果差异     | 浏览器输入"MBTI 人格分析"                | 有 Key vs 无 Key 输出差异巨大                     |
| 优化提示词      | `plan_generator.py` 第 323-355 行 | 核心要求 7 条：深入理解主题、体现领域特有概念……                |
| 优化主题扩展提示词  | `topic_analyzer.py` 第 114-124 行 | 要求 LLM 增加活动形式暗示                           |
| 演示 PPT     | 5-6 页                           | 架构图 + 8 步工作流 + 确定性引擎 vs LLM Agent + 演示截图  |
| 准备 .env 文档 | —                               | 告诉老师如何配置 API Key                          |
